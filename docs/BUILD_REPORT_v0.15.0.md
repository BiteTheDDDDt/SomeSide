# SomeSide v0.15.0 武器动作与界面更新

## 行为变化

- 八种主武器都有独立攻击动作：步枪后坐、霰弹枪后坐与回膛、磁轨枪重后坐与散热、喷火器持枪震动、回旋刃投掷与接回、权杖举杖施放、光矛前刺，以及弧刃的起势、横扫和收刀。手臂和上身随武器动作，原有跑步、跳跃和脚步位置继续保留。
- 弧刃不再按下立即结算伤害。动作时长随攻速缩短，22% 时开始快速挥动并播放挥刀声，40% 时由主机结算一次原有扇形伤害和命中治疗；死亡、切换主武器、换关会取消尚未命中的攻击。刀锁定出刀方向，其他武器保持实时鼠标瞄准与原有射速、伤害和弹道。
- 实际枪口、枪口光与新弹显示起点跟随同一个武器姿态；物理枪口与碰撞不随装饰性后坐改变。修复回到待机时刀柄位置和刀身尺寸的瞬跳，起止姿势连续。
- 联机本地预测立即播放，不被自己的权威回包重新触发；队友可以只靠快照恢复动作进度。表现事件逐条携带关卡编号，跨通道晚到的旧关事件丢弃，未来关事件等待画面切换后播放，暂存最多 192 条。单机暂停冻结攻击动作及尚未响起的挥刀声。
- 主菜单、选角、合作大厅、设置、暂停、背包、地图和结算统一切角面板、像素字标、裂隙装置、角色与装备展示、琥珀色主按钮和键盘焦点。中英文共用布局，战斗 HUD 保持原有紧凑面积。装饰采用原生 CanvasItem 缓存绘制，没有新增持续重绘的 UI 动画或大型纹理。

本次复用已有像素精灵，增加武器、手臂和上身的程序姿态动画；没有生成新的逐帧角色 PNG。音库继续复用 v0.14 的独立武器音效。
