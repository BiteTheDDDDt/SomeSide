# SomeSide 0.11.0 构建验收报告

验证日期：2026-10-05。引擎：Godot 4.7.2 stable / Windows x64 / OpenGL Compatibility。上版完整记录保留在 `BUILD_REPORT_v0.10.0.md`，Git 标签 `v0.10.0`。

## 本次交付

- 修复两种叠加的运动抖动：60 Hz 角色位置阶跃与逐帧平滑镜头不同步；高分辨率精灵直接缩小采样时，亚像素移动导致身体细节不断改变。
- 本机和主机使用前后固定步长样本插值，角色、镜头、武器与弹丸共享显示位置，不外推越过已知碰撞位置。显示延迟最多一个物理步；客户端预测角色按预测 tick 采样，远端保留原网络插值。换关、传送、时间回退和生死变化重置样本。
- 精灵帧预采样到共用尺寸和整数锚点的逻辑像素图集，在实际窗口的物理像素空间对齐；移除身体额外的程序浮动。三张原 PNG、裁剪清单、碰撞体、移动数值和网络协议均未改变。新增图集 1,159,168 bytes（约 1.11 MiB），独立上限 8 MiB；原三张纹理 18,872,976 bytes，上限 64 MiB。
- 新发射的主武器弹丸从当前显示枪口接入，首次显示不产生倒穿枪身的尾迹；权威出生点、速度、飞行距离和碰撞不变。
- 清除 “Expedition Program / Early Expedition” 等装饰性文案。菜单、选角、大厅、设置、操作指南、暂停、结算、背包和地图统一暗青面板、细边框、暖金主按钮及键盘焦点；角色卡显示真实精灵，房间成员按姓名/角色/准备状态分栏，结算使用区域/时间/击杀统计卡。中英文同步整理，页脚仅保留版本。
- 游戏内保留紧凑 HUD 和醒目金币；背包、地图将 FPS 移到顶部留白，关闭后恢复金币下方，避免穿过面板边框。

## 自动与原生验证

最终覆盖 **23 套 / 1220 项通过 / 0 失败 / 无运行时错误**。完整测试运行记录 `tools/results/v0.11-final-tests.log` 为 1216 项；之后仅新增四项远端插值断言，生产代码未改，单独重跑运动套件 51/51：`v0.11-actor-motion-final.log`。汇总为 `v0.11-test-summary.json`。

- 保留原有模拟、输入、跳跃、掉落、AI、四人压力、枪口、饰件、UI、双语、FPS 与粒子回归。新增运动测试覆盖固定步长插值、预测角色、远端不重复平滑、传送/切关/暂停处理、新弹丸与缓存预算。
- 原生 OpenGL 运动测试 89/89、既有像素角色测试 25/25；最近邻采样断言保持。14 种角色在 1×、1.5×、2× 窗口缩放下，各经历 16 个亚像素相位，固定姿态像素均稳定。证据：`test-actor-motion-native.log`、`test-pixel-actors-v011-native.log`，stderr 空。运动原生运行早于新增的四项远端断言，后者由最终无窗口运行覆盖。
- 固定姿态 32 次平移对比：修复前各窗口缩放产生 32 种不同身体细节，修复后各为 1 种，相邻图像差异为 0。证据：`actor-motion-before.json`、`actor-motion-after.json`。96 帧真实跑跳射击对照：`actor-run-v011-before-after.gif`（左旧版、右新版）。
- 独立检查 30/45/60/75/120/144/165 Hz 下持续向右移动，镜头跟随稳定段均无可见反向帧。120 Hz 原先相邻显示位移约 -1.995/+2.005 px，修复后只余浮点噪声。证据：`v011-motion-review-before.json`、`v011-motion-rates-review.json`。
- 检查 29 张真实中英文 UI 截图，包括长房间昵称、大数值结算与完整图鉴。独立 20 页面文本宽度及真实焦点链检查无问题，用户偏好文件未变。证据：`v11-*.png`、`v011-ui-independent-review.json`、`v011-capture.log`。
- 最终 EXE 菜单和实战分别原生运行七秒；实战完成 420 tick。两次均正确加载 14 actors / 3 source textures / 1,159,168 baked bytes / 0 errors，FPS 可见；exit 0、stderr 空。证据：`v011-export-menu.*`、`v011-export-play.*`。
- 最终 EXE 英文主机与三个中文客户端进行真实本机四进程 ENet 验收，经过三关并观察到九种普通敌人、三种首领和危险预警。四端 passed=true、exit 0、runtime_errors=0，精灵资源齐全。证据：`network-export-biomes-bilingual-20261005-013856/summary.json`。尚未验收公共互联网环境。

## 性能复核

NVIDIA GeForce RTX 5070 Ti Laptop GPU，1280×720，关闭垂直同步与帧率上限；固定快照，关闭物理、网络和音频。每场预热 120 帧、采样 360 帧，移动镜头。密集场景含四名角色、44 敌人、160 弹丸、24 掉落物及六个危险区。以下是画面与 HUD 的成本，不代表完整实战 FPS。

| 场景 | v0.10 p50 / p95 ms | v0.11 p50 / p95 ms |
| --- | --- | --- |
| 安静雨林 | 7.914 / 10.038 | 7.930 / 10.627 |
| 密集雨林 | 19.497 / 21.875 | 19.004 / 23.179 |
| 密集峡谷 | 14.672 / 17.816 | 15.220 / 19.214 |
| 密集遗迹 | 18.007 / 21.212 | 19.207 / 22.700 |

本版重点是运动一致性和界面，不宣称帧率提高；插值带来少量 CPU 工作，密集场景仍可能超过 16.67 ms。证据：`perf-v10-final-moving.json`、`perf-v11-final-moving.json`（含源码哈希和硬件信息），最终 stderr 空。
