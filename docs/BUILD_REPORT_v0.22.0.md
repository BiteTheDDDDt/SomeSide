# SomeSide v0.22.0 — 24帧完整动作与开局职业选择

2026-10-09（10月8日开始）。保留当前背景、角色、怪物和特效造型。本轮没有新增或修改PNG原画，24帧是复用关键姿态、关节和局部材质形变生成的动画姿态数据，不代表每段新画了24张图片。

## 修改

- 新增有限的24姿态动作系统，首次烘焙、随后复用，按动作进度或位移播放，支持非均匀关键时刻及插值。游戏渲染FPS不受24帧数量限制。
- 两名角色的前跑、后退、停步、起跳/上升/最高点/下落、落地和冲刺动作接入。完整跳跃合计24姿态；支撑脚仍钉在世界坐标。待机枪口保持稳定，只增加克制的衣摆跟随。
- 七种远程武器和弧刃每段完整动作各24姿态；保留原后坐、回膛、前刺等区别，近战明确保留蓄势顶点、命中方向及收招顶点。
- 全12种怪物增加分区关节动作，完整攻击共24姿态：10蓄势、5释放、9恢复。颈、前后肢、翼/尾有各自支点；身体仍为实体插画。各类真实攻击时长保留，器官在形变后重新绑定原发射点。
- 孢子、地刺完整效果共24姿态：8准备、8伤害、8破碎收尾。沿用原非均匀原画节奏，各阶段只能访问自己的帧区段；形变后再次裁切到真实危险范围。
- 瞬移区分24姿态的准备、离开端收拢与到达端展开。弹丸、各类枪口/命中、飞弹、波、光环、护盾、爆炸、治疗及激光内部材质等同步接入。
- 激光继续按共用的权威包络射出、保持、变细消失；新增材质变化只作用于内部线束。红色预警、方向锁定、发射点、碰撞与伤害时长未改。
- 修复弱枪口闪光缩短时的轮廓自交，所有纵向节点一起收缩；加入从弱到强、完整生命周期的多边形回归检查。循环旋转跨第24帧使用角度插值，避免倒转。扑击爪尖发射点同步使用同一关节变换，逐帧检查其与实际网格顶点一致。
- 单人和“再玩一次”先选择职业，再确认开始；标题移除独立角色设置入口。合作大厅直接点选两种职业，保留原角色同步与准备规则。更新中英文本。
- simulation.gd、输入和联机权威逻辑未修改；新增纹理显存为0，动作表最多512段，网格缓存最多384份。

详细覆盖与复验命令见 [MOTION_CLIPS_24.md](MOTION_CLIPS_24.md)。上一版记录保存于 [BUILD_REPORT_v0.21.0.md](BUILD_REPORT_v0.21.0.md)。
