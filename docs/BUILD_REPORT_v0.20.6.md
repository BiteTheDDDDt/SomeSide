# SomeSide v0.20.6 构建记录

本轮延续用户已认可的怪物块面插画，并将其推广到当前使用的角色、物件和攻击反馈；同时按追加意见把怪物近黑阴影提为炭灰。日期：2026-10-07。

## 素材覆盖

- 十二类怪物：透明图集提灰，保留原配色、造型、UV布局与攻击锚点；排除冲锋兽区域混入的邻图碎片。高不透明像素中亮度低于0.16的比例由34.97%降至0.59%。这是像素统计，不是主观质量评分。
- 游侠、先锋：各四张插画姿态（待机、上升、下落、冲刺），替换游戏、主菜单及角色选择页的旧像素身体。地面前进/后退继续使用按位移驱动的两条腿和接地锚点，腿甲改用平滑矢量素材；保留独立瞄准、挥击和后坐。
- 八把主武器：重新设计大轮廓与三层材质，共享手持/掉落/库存图形。枪口位置、长度、攻击动画和移动机构保持原接口。
- 五类设施：宝箱、三选一、献祭、战斗祭坛、装备柜重绘弧形壳体与硬边明暗，包含未开/开启/锁定和战斗激活状态。
- 全部43种库存/掉落物：保留功能辨识形状，统一材质、灰色阴影与采样；稀有度标记保留原语义。
- 角色附着物、部署炮台、金币、传送门、应用图标和菜单边框同步调整。炮台共享步枪外形；菜单采用平滑文字和曲面结构。原有地形、环境色调和分层背景保留。

## 攻击特效

枪口按步枪、霰弹、磁轨、电球、长矛、回旋刃区分；近战使用沿真实挥击角度展开的收尖弧带。命中为方向明确的短碎片，爆炸使用不等长弧片和少量实心碎块，减少整圈警戒式轮廓、均匀放射线和柔光。喷火、引力、陨击、冲刺、治疗、连锁电弧也接入同一硬边形状体系。

追踪弹使用实体弹体，落地冲击波使用厚薄变化的弧片，霜环、临时装甲与主动护盾采用分段弧形片。回旋弹直接使用手持星刃图形。现行这些效果不再调用旧纹理动画；旧资源保留用于兼容与历史测试。

红色虚线预警、激光0.55秒生效及距离渐淡继续保留。未修改模拟、攻击时机、伤害、瞄准和命中范围。复测中修复雷杖火光收缩时的自交，以及爆炸末尾亚像素碎片的三角化错误。

## 交付与边界

发布包：dist/SomeSide-v0.20.6-windows-x64.zip、dist/SomeSide-v0.20.6-web.zip。未上传itch或推送GitHub。

内置图像生成工具制作了角色PNG和怪物提灰版本；完整提示词与资源说明在 assets/art/unified-v0206/ART_NOTES.md。其他物件和特效由项目原生SVG/绘制代码实现，便于复用锚点与状态。

角色不是完整逐帧动画序列；移动采用插画上身与原有接地腿部组合。大规模道具叠加的主观观感、低端设备性能、Firefox/Safari以及公网多人本轮未重测。单机原生与Chrome检查不代表所有设备均已验收。
