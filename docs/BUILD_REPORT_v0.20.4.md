## 红色虚线与距离衰减

- 预警采用9像素实线 / 6像素间隔，2Hz红色明暗脉动，亮度下限68%；4像素暗衬与1像素暗红连续线保证间隙仍能读到完整边界。主要红线2像素，装饰1.1像素；均按实际逻辑显示尺寸绘制。
- 激光准备为空心；生效才出现填充的硬边几何束。外层、内层、亮芯分别从近端不透明线性衰减至远端14%、24%、38%，并保留细实线边缘。不是把射程缩短，也不是在伤害结束前按时间隐去光束。
- 准备/生效共用权威危险区的起点、方向、长度、半径及胶囊端部；圆形预警直接使用危险区中心与半径。装饰位于边界内部。
- 所有生效危险形态在倒计时结束后移除。命中余效仅为短碎晶、少量珠点或开放爪弧，持续0.14秒，没有完整残留光柱或危险区域轮廓。
- 哨卫炮口固定于实际激光源点，炮体后坐；喷吐嘴沿实际弹丸生成公式定位，颈部在口后收缩。左右/上下/斜向锚点均覆盖测试。
- 先画生效危险区，再画准备中的边界，避免另一条光束盖住预警。
- 没有改变瞄准、前摇、射程、伤害、移动或冷却。simulation仅为hit事件添加来源类别、敌人ID和方向，便于选择对应命中效果。
