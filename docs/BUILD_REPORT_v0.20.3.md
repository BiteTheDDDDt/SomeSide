# SomeSide v0.20.3 构建记录

日期：2026-10-06。引擎：Godot 4.7.2，GDScript，Compatibility 渲染。

## 本次变化

根据实际游玩反馈，瞬发攻击重新优先保证反应时间和预警可见性。准备动画继续保留，同时恢复从第一帧就可见的明确几何提示。

| 攻击 | 完整准备时间 | 提示 |
| --- | ---: | --- |
| 普通／首领直线激光 | 1.5秒 | 固定方向的全长琥珀色弹道、宽度边界与淡色填充 |
| 首领交叉激光 | 1.8秒 | 所有方向同时显示 |
| 潜地 | 1.5秒 | 暗色描边的完整范围圈、增亮的土块扰动 |
| 地刺／首领孢子爆发 | 1.6秒 | 各落点独立范围圈，内侧进度弧 |
| 夜蛾孢子 | 1.4秒 | 放大并加亮的孢囊、清晰范围圈 |

- 激光预警两端补齐实际半径的半圆，填充与描边均覆盖完整胶囊范围，与原有线段－圆碰撞一致。准备阶段使用琥珀色，实际伤害阶段才显示紫白亮束。
- 孢囊由18–26像素增至36–44像素，取消准备期的额外暗化与半透明，并增加小范围暗衬。地面准备素材高度由14增至22像素。普通、最低特效、减少动态效果下都保留完整预警。
- 排查到的普通孢子和首领孢子范围攻击均先创建未激活的危险区，没有发现直接跳过准备生成酸液的代码路径。原素材过小、偏暗且可能与角色重叠，能够解释难以辨认，但不能据此断言已复现用户看到的每一种情况。
- 修正新危险区在创建当tick就扣减倒计时的问题：第一份快照保留完整准备时间，随后与怪物动作同步推进，避免伤害比动作提前一个模拟步生效。
- 首领先选择本次攻击类型，再决定前摇。冲锋、扑击、飞弹／齐射的速度、前摇、伤害与冷却未改；瞬发攻击的伤害范围和生效时长未改。
- 本次不新增图片素材，沿用v0.20.2图集；18类效果仍共享8张纹理，总预算32 MiB。
