# SomeSide v0.21.0 — 动作重量与关键姿态

2026-10-08。保留已选背景、角色、怪物与特效造型，本轮只补姿态、动作衔接与节奏。

## 检查现状与实际修改

- 角色原先每人四张插画（基础、上升、下落、冲刺），跑步由位移驱动的两条程序关节腿完成。现各补三张真正的新姿态：即时起跳伸展、空中最高点、落地压缩。没有将所有动作统一扩为16或24张。
- 新的画布私有动作历史识别落地，按上一个空中样本的下落速度给出有限压缩强度，25ms快速下沉、55ms附近短暂承重，220ms内回弹站稳。移动、再次起跳、冲刺或攻击立即打断；模拟层不等待任何姿态。
- 保留支撑脚的世界坐标约束及急停120ms回收。髋部增加不足1px的重心起伏，肩部轻微反向旋转；落地混合使用固定两条IK腿，避免将两幅原画的腿叠成重影。上身姿态按同一肩部锚点对齐，脚底不随上身反作用漂移。
- 保留武器既有后坐、回膛、投掷、前刺及近战曲线。增加有限的躯干反作用和肘部跟随；轻武器短促，重武器更明显。身体和握持点共用同一姿态采样，鼠标瞄准仍独立。多次射击替换采样，角度和偏移不累积。
- 原怪物主要靠单张插画的网格形变，32档是缓存形变量化，并非32张原画。现在扑击怪、喷吐怪、石头首领各有四张真实关键姿态，表现蓄势、释放、支撑与恢复；扑击在真实冲刺期间保持伸展，直到后段收势。喷吐口逐帧绑定现有发射点，爪击弧从各姿态的爪部产生。
- 样例通过后，共用动作采样接入其余怪物：沿用原画与局部网格，激光、孢子投射、治疗、瞬移保留不同释放/恢复时长。没有给其他怪物声称新增原画。
- 孢子、地刺各增加爆发过渡和破碎余效两张，共十张原画：四准备、四攻击、两结束。220ms攻击阶段依次分配约22/37/90/70ms，200ms余效分为约96/104ms；只在同阶段末端小范围混合，准备不能预显完整爆发，结束只留下低矮离散碎片。
- 瞬移仍使用原八张图，出发端先宽后窄快速收拢；到达端先展开、短暂停留再消散，240ms事件寿命不变。原红色渐进虚线和伤害阶段切换保留。

## 素材、资源与边界

- 内置image_gen生成两张角色/怪物姿态图集和一张特效补帧图集；完整提示词、来源、原图保留方式见 assets/art/motion-v0210/ART_NOTES.md。没有编辑生成PNG像素。
- 新增三张图集导入长边限制1024，额外RGBA纹理约8.3MiB；角色/怪物素材上限14MiB，地面特效和瞬移四图总上限10MiB，自动检查实际导入尺寸。
- 纹理与姿态视图复用；怪物网格仍限制384个缓存，角色历史限制64个实例。静止原画走单次绘制，纯上身仿射动作只绘制一个四边形，复杂衔接才使用短条带网格。
- 本轮scripts/simulation.gd未改动。所有动作由秒数、位移、现有权威计时器驱动，不更改碰撞、跳跃、射速、预警、攻击窗口或联机判定。
