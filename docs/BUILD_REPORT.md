# SomeSide v0.20.7 — 怪物攻击与激光生命周期

2026-10-08。补齐上轮没有更新的怪物攻击路径，保留已认可的角色、怪物图集和环境背景。

## 本轮改动

- 孢子和酸液弹改为有前后结构的实体囊体、局部硬边亮面和短尾滴；移除预警孢子的深色圆形衬底、黑色外描边与中间黑缝。灰绿阴影直接参与身体形状，不再外套一个黑圆。
- 晶体弹使用不等长五边轮廓和三层切面，准备弹与发射弹共用绘制；孢子区域改为不规则酸液块面和囊粒，地刺增加顶端切面，闪现使用收尖裂口；扑击爪弧和冲锋碎块随身体移动。没有改变这些攻击的速度、瞄准、伤害或时机。
- 全部区域预警共用红色虚线，删去内侧暖色进度弧和连续底线。深色可读性衬边只贴着红色短划线，不组成第二条警戒线。
- 普通哨卫、Boss直射与交叉激光均使用单条红色虚线箭头：沿锁定方向渐长，蓄力65%时到达射程末端；实际发射即撤去。中心线提示方向和射程，不再表示完整伤害宽度。
- 发射口切面聚拢蓄力；激光45ms内向前射出，35ms内展开，保持后在最后210ms收细消失。继续保留距离渐淡，总持续550ms不变。
- 新增纯数学 beam_envelope.gd，由模拟与渲染共用长度/宽度变化。激光伸出前的远处与收束后的外侧不会继续受到隐藏伤害；过期攻击不再计算最后一帧命中。一次攻击对同一玩家仍只伤害一次。
