# SomeSide v0.18.0 武器与道具美术更新

## 变化

- 重绘8把主武器：分离枪托、机匣、握把、枪管和活动机构，以深色轮廓、金属明暗面、铜色连接件及少量内嵌能源条表现材质。弧刃采用细长刀身、刃脊和独立护手。`weapon_art.gd` 同时提供手持与图标主体，图标以实际轮廓等比填充，保持比例。
- 重绘24种被动遗物和8种主动装备。抽象符号改为芯片、双联电容、目镜、培养核、回路罐、机械翼、引力装置等实物组件；统一切角底板和稀有度短点。HUD、提示和图鉴使用各自实际显示尺寸的缓存与最近邻采样；未持有图标提高可见度。
- 地面物品展示透明实体外形，脚下保留颜色、短点与轻量光柱，选中时有独立括角；有副作用的道具仍显示风险三角。物品视觉抬离地面，阴影跟随真实落地位置。拾取仍需主动按E，切换目标与换装规则不变。
- 24种角色饰件改为贴身像素部件。肩部电弧/回声/新星不再使用立杆光球，目镜、胸件和肩甲缩小，保留脸和持械轮廓。六槽选择规则及叠层上限不变，颜色与对应图标一致。
- 武器、饰件首次使用时烘焙并缓存。8个武器主体及3个活动部件共104,544字节；72种饰件层级裁去透明外围后共32,752字节。饰件每槽一次贴图，最多六槽；没有增加AI生成PNG或外部素材依赖。

伤害、射速、弹道、枪口端点、攻击动作时序、碰撞体、掉率及联机模拟未修改。

- 2026-10-05，Godot 4.7.2：42套回归、2041项通过、0失败。结果：`tools/results/tests-v018-summary.json`。初次运行有4条旧测试把技能图标固定为72px资源；断言已改为实际显示尺寸，并保留来源与最近邻采样校验。初始日志与从该套件继续的日志分别是 `tests-v018.log`、`tests-v018-tail.log`。
- 新增武器绘制46项，覆盖8把武器的真实像素枪口端点、有效SVG、透明边界、图标裁切、独立外形和固定缓存；已有瞄准、攻击动作、近战、联机预测显示测试通过。
- 图标检查覆盖40件物品、16/24/32/48/64/128/256七种尺寸，检查尺寸、缓存、唯一图像、透明四角和实体轮廓；40张有框图与40张透明图都可用。商店稳定性35项通过。
- 饰件原生展示审计374项通过，包含全部24件、三个显示层级、双角色、六槽组合、99层、左右瞄准和快照不变性。原生截图复核了单件轮廓、脸部可见度及持械遮挡。
- 实际游戏主场景生成7张中英文HUD、背包、武器图鉴及近景截图，用户偏好文件保持不变。独立Windows导出程序实际开局运行480个tick，完成战斗和截图，无运行错误。记录：`tools/results/export-v018-report.json`。
- Chrome154跨源iframe标准验证14/14通过：全屏、语言/FPS持久化、单人入口、960×540与1920×1080画布、实际音频和541tick模拟均正常。冷启动就绪4.88秒；浏览器、网络和Godot错误为空。该次浏览器使用AMD 610M/ANGLE D3D11；记录在 `tools/results/web-v018-chrome/`。此数据不是跨设备性能保证。
- Windows/Web导出成功；Web ZIP离线审计通过，11个文件，根目录`index.html`、资源引用与文件大小均正确。
- 只读整合审查未发现绘制状态泄漏、无界运行时缓存或依赖循环。没有修改角色与怪物PNG；本次未重复四人网络或跨设备帧率基准，既有联网与数值实现未改。
