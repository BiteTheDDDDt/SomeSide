## 兼容边界

逐行比较基线确认旧43个物品记录、9个普通怪物记录保持不变；旧图片没有修改。旧制导没有mode字段，继续最近目标、有限辅助、超过原寻敌范围或错身后停止；旧制导54项回归通过。游侠、先锋技能入口与数值、原武器间隔、原装备冷却和旧存档职业ID保留。

新弹丸用显式配置进入专用扫掠分支：实体遮挡与身体按首次接触顺序挡弹，浮空单向平台不变成墙，制导路径以最多1/120秒细分。初始枪管段也扫掠，视觉从实际动画枪口开始。目标只在生成节点寻找，之后按ID读取；没有飞行中改锁。客户端移动预测不能施法或部署，所有新命中、冷却、目标与额度由主机决定。

生产地图当前只有底部地面声明为solid_cover；未来实体墙需显式加入，不把背景剪影当可碰撞墙。晶蛾锁定使用目标玩家实际报送视口与保守660×420内部的交集；晶体离开所有存活玩家的保守可见内部时无害消散。没有屏边飞弹箭头，这一保守替代会缩短有效射程。

旧类别入口仍是88%被动/7%武器/5%装备；同一候选集合里旧条目的原始相对权重不变，但扩充池子使绝对出现概率下降。以第一关游侠、无历史/地面/设施保留且排除四件初始装备为例：ambient武器池弧针25%、寻星7.69%，旧武器概率乘.6731；ambient装备池信标7.08%，旧装备概率乘.9292。它们都是类别内条件概率，不是怪物全局掉率。所有候选、稀有度及排重会改变实际值。完整例子见 [TRACKING_CONTENT.md](TRACKING_CONTENT.md)。

峡谷普通探索导演新增12%晶蛾分支，其余88%保留旧52:23:25比例；强制飞行回退仍用原drone。峡谷试炼均匀池由3种扩为4种，旧每种1/3变1/4。雨林、遗迹池保持原样。

## 自动化平衡探针与待验证项

tools/check-tracking-balance-v0230.gd运行20组12秒武器测试：单体首领体积、10个密集目标、移动目标、近身绕行、单向平台高低差；四把枪应用同样5°瞄准误差，禁用职业额外弹、技能、装备与遗物，保留普通暴击率。目标生命提高以测命中，AI关闭，因此不是完整真人难度结论。

移动目标例子：脉冲步枪18/60命中、12有效DPS；弧针33/56、21DPS；寻星9/10、31.67DPS。静止首领工况脉冲40.67、弧针33.83、寻星34.83有效DPS。追踪优势主要来自命中率；两把新枪名义DPS约35与31.67，没有自带范围、穿透或爆炸优势。慢枪完成射击后的在飞弹会造成窗口末尾误差；结果不是全面胜率或严格统计置信结论。

另用实际AI、无无敌/初始遗物、三职业各自初始装备和相同基础走位控制运行12个40秒压力/首领工况。六怪近身围攻三职业都清场；织轨者4.25秒、剩90生命。孢冠首领织轨者24.27秒清场、剩71生命；岩石与棱镜首领分别18.52和27.48秒死亡，首领还剩336和160生命。游侠也在岩石工况死亡，先锋三首领均清场。

因此不能声称织轨者平衡已经完成：无道具首领生存偏弱，控制器也不会依据具体预警精准闪避。建议下一步真人复测；若复现，可先单独试刻印冷却8→7秒、信标首脉冲.4→.3秒，保持36/54单次伤害预算，以较早火力窗口改善压力。该建议没有在本版悄悄实施，没有赠送冲刺/架盾。完整自动化结果在tools/results/tracking-v0230/balance.json及交付证据摘要。

尚未验证：真人长局与合作分工平衡、公网不同电脑/高延迟网络、Firefox/Safari实玩、低配置真机帧率、实际itch.io上线。本轮没有上传itch.io或Push到GitHub。

## 素材与性能成本

织轨者图集使用内置image_gen，以旧玩家插画为风格/比例参考生成独立新职业，7个关键姿态，原RGBA复制不改像素，运行时Atlas校准。完整提示词与来源记录：[provenance.json](../assets/art/tracking-v0230/provenance.json)。图集1536×1024、无mipmap，RGBA估算6MiB；单纹理与最多7份Atlas复用。其他新物体用项目原生SVG/几何与缓存流程。

保留旧缓存上限与全局280弹，新增尾迹最多10点/约100长度、信标4台、旧炮台4台、寻星每人3发、晶蛾每怪1发/每玩家2锁定。旧炮台替换只淘汰最老旧炮台，不挤掉队友信标。新增两把武器后的13项纹理缓存低于2.6MiB；合成音频总PCM仍低于2MiB。浏览器检查是本机无头Chrome环境，不能据其结果承诺所有硬件60FPS。
