# SomeSide v0.18.1 平滑武器与图标

## 变化

- 将脉冲步枪试验推广到全部8把主武器和3个活动机件。相同SVG以4倍精度烘焙，透明边缘补色后生成mipmap，使用线性采样；保持原来的逻辑绘制范围、枪口端点、握持位置与攻击动作。
- 40件物品及角色技能/设施图标共用平滑SVG纹理，覆盖HUD、背包、图鉴、掉落提示、地面物品和三选一商店。请求的逻辑尺寸保持不变；内部栅格分辨率最多256×256，缩放和旋转不会放大界面布局。
- 图标纹理自带采样设置，同一画布上的角色、怪物和角色饰件继续使用原本的像素采样。未改变源SVG造型、精灵PNG、战斗数值、拾取或联机规则。
- 图标缓存按含mipmap的实际图像字节计费，最多32MiB，优先保留最近使用的纹理；被移出缓存的纹理仍可由正在显示的控件持有。纹理缓存未命中时才烘焙SVG，不逐帧渲染矢量。
