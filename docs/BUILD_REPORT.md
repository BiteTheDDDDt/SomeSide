# SomeSide v0.9.0 构建验收

2026-10-05，Godot 4.7.2。交付 dist/v0.9.0/SomeSide.exe 与 dist/SomeSide-v0.9.0-windows-x64.zip；旧报告归档为 BUILD_REPORT_v0.8.0.md。

本版加入短按低跳、长按高跳；长按保持原最高轨迹，羽翼空跳也可控制高度。A/D 与左右箭头采用后按优先、松开回退，自动重复不抢方向；失焦和暂停清理按键。网络持续按住状态采用最新输入，过期时释放。60 Hz 实测一帧短按27.76 px、0.15秒95.04 px、长按120.85 px；两角色三关全部平台和设施仍可无道具、无冲刺长按单跳到达。

## 性能

NVIDIA GeForce RTX 5070 Ti Laptop GPU，1280×720，原生OpenGL，关闭VSync和帧率上限。实际main展示流程与world绘制使用固定权威快照，停止物理、网络、音频；每场预热120帧，统计360帧。密集场景四角色、44敌人、160弹丸、24地面物品及危险预警。

移动密集场景p50降低约64%–67%，固定密集场景约73%–74%。固定雨林绘制调用8212→2082，world绘制CPU中位36.91→11.60 ms；移动雨林调用7440→2345。这是场景缓存、实体图集、目录索引与HUD的综合收益，不代表完整实战或其它硬件的保证帧率；密集场景仍超过16.7 ms，有后续优化空间。

证据：tools/results/perf-v09-{baseline,after,baseline-moving,after-moving,comparison}.json；脚本tools/perf-v09.gd。基线使用隔离v0.8 HEAD，最终after七个源码哈希与v0.9交付源码一致。旧固定基线夹具退出时有未入树默认World节点的RID泄漏；该节点未参与测量，夹具已释放它，最终固定/移动/保真运行stderr均为空。

地形缓存最多40项、48 MiB颜色纹理估算；移动测试峰值22项、31,823,164字节。底层地板保持完整深度，移动视差、动态植物、水流、旋转地标和预警保留。普通敌人/敌方弹丸图集在菜单一次预热，独立测量首次ready537 ms、setup CPU15.8 ms；颜色纹理计划28.8125 MiB，实际OpenGL texture monitor增量57.625 MiB，低于64 MiB测试上限。友方尾迹保持原矢量绘制和出生点裁剪。上述场景缓存预算不等于总显存，SubViewport可能有额外缓冲。

物品查询每批5000次微基准中位323.781→5.190 ms，校验和相同，返回副本隔离不变；UI只在内容、价格、风险、装备、候选顺序、语言或详情状态改变时重建样式。

## 验证

19套headless测试共1055项全部通过，见tools/results/v0.9-final-tests.log及v0.9-test-summary.json。新增移动62、输入51、实际main输入35、地形缓存24、图集布局/headless20；原有玩法、地图、武器、敌人、双语与金币回归继续通过。

另外原生图集测试28/28通过，v09-sprite-atlas-final.log/.err无错误；敌人前景平均RGB差约3%，弹丸约1.36%，保持原验证阈值。全部敌人变体、冲锋准备姿态、敌我弹丸与不同尾迹长度经过图像对照。三关低镜头地板、缓存/原画面、中英文新指南与实际游戏均已目视检查。
