# SomeSide v0.19.0 设施预览与导引攻击

## 变化

- 重做补给箱、三选终端、生命祭坛、战斗信标和装备仓：箱盖、护板、玻璃仓、金属支架与能源组件采用4倍精度SVG纹理和mipmap。开启、锁定和挑战中具有独立外观。合法缓存键最多16种，完整缓存约5.33MiB，纹理仅在首次使用时生成。
- 屏幕内未开启设施直接显示主机已确定的奖励图标、名称和真实代价。金币与生命费用分开标识，付不起时费用变色；战斗信标显示挑战或剩余敌人数。附近仍可查看完整效果、风险并按E选择，奖励内容不会因为预览而重抽。中英文显示均已接入。
- 三选一的价格牌固定错开，屏幕边缘按整组避让；价格牌不跟随悬浮图标起伏。原有24px图标和稳定ID相位保留。
- 万雷权杖雷球出膛时在瞄准方向两侧各20°、520距离内锁定一个目标，以原780速度最多导引0.65秒，每秒最多转80°，累计不超过22°。原射速、32基础伤害和邻敌20伤害连锁保留。
- 修复导引者保留0.85秒起手，能量弹速度从230降至210。仅在发射时锁定前方两侧各16°、620距离内的玩家，先直飞0.22秒，再以每秒24°、累计最多12°有限导引。两种导引都不重新选目标；过身、离开范围或目标失效后永久直飞，弹丸原寿命不变。
- 激光以收束流线、聚能核心、压缩光圈、亮束释放和余辉表现攻击，怪物有连续准备与恢复动作。冲锋和跳扑使用贴脚扬尘，吐弹使用口部鼓起的液团，机械攻击保留聚能。激光方向、长度、圆头危险区和伤害时机均保持主机锁定值；最低特效与减少动态模式仍显示完整危险边界。

## 验证

- 完整Godot 4.7.2回归：46套、2438项通过，0失败、0运行错误、0警告。日志 `tools/results/tests-v019.log`，摘要 `tools/results/tests-v019-summary.json`。最后的标签避让调整另做针对性回归，见下方最终验证记录。
- 导引新增54项检查：真实偏轴命中、原直线对照、贴身和连续碰撞、连锁伤害、转角/时间/寿命上限、死亡与移除目标、普通移动和基础单跳躲避、快照序列化恢复、预测不伤敌、切关清理与实体上限。原生六格实拍及轨迹记录为 `tools/results/guidance-native.png` / `guidance-native.json`。
- 敌人动作新增51项检查：足底锚点、准备到释放连续性、恢复归零、低FX危险几何不变、真实哨卫的锁定/释放/过期、绘制不修改快照。原生1x画面、阶段图和90帧60fps录像位于 `tools/results/enemy-attacks-v019/`；`attack-preview.webm`为2x细看。
- 设施测试覆盖真实奖励/币价/血价/试炼状态、已购买三选一、双语、布局稳定、边缘避让、平滑纹理和有界缓存。原生前后图册及实际HUD下的中英文截图位于 `tools/results/facilities-v019/`。
- 最后从实机画面发现下层宝箱标签会压住上层终端，增加局部避让和底座连接线后复测设施107项、商店35项，全部通过。按每套最新结果汇总共46套2440项，来源与最终生产文件哈希见 `tools/results/tests-v019-final-summary.json`。
- 四人压力测试各运行120模拟秒：44敌堆积和12层构筑保持有限数值及既有实体预算。当前机debug观察到最慢模拟步约1.96ms/2.36ms；这不是渲染帧率或跨设备保证。
- 刻意同时放满280弹和44敌的debug微基准，单步约13.92ms（去掉导引的对照）/14.94ms（全部导引）。导引仅发射时搜目标，后续每步最多建立一个敌人ID索引，保留有界转向与查找；原始输出在完整测试日志中。
- 独立Windows导出程序运行480tick，34个事件、1次击杀，正常截图并以0退出。`tools/results/export-v019-report.json`，原生日志没有运行错误。
- 导出程序的四人高级联机、房主英文/客户端中文验证通过；三客户端分别接收712/710/714次快照，全部观察到带锁定目标的导引弹、炮台、延迟效果和时序状态。记录：`tools/results/network-export-bilingual-20261006-161450/summary.json`。本轮为同机本地网络实测，未重跑网络丢包模拟。
- Chrome154 Web验证14/14通过，实际541tick、跨源iframe、960×540/1920×1080画布、全屏、声音、语言/FPS偏好保存均正常，浏览器/网络/Godot运行错误为0。冷启动就绪5.31秒；该浏览器使用AMD610M/ANGLE，末次FPS读数27，与上版同机测试的末次读数一致；这不是持续帧率基准。记录：`tools/results/web-v019-chrome/report.json`。
