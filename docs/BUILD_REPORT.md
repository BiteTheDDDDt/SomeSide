# SomeSide v0.17.0 追击、步态、角色技能与金币更新

## 行为变化

- 地面怪物按玩家实际落脚平台规划追击跳跃，玩家普通空中短跳不再触发全群跟跳。每只怪有独立反应延迟、跳跃冷却与跳速差异；可以追上高台、逐层台阶并跨越窄缺口，既有跃击与冲锋前摇继续保留。
- 角色地面移动改用明确的两条双关节腿：支撑脚固定在世界坐标，摆动脚抬起、回摆、落地。停止时短暂收脚，前跑和后退采用不同步幅；腰线下旧PNG腿完全裁掉，上身、武器动作与空中姿势保留。腿部装甲为小型原生像素部件，与两名角色配色一致，没有新增AI精灵PNG。
- 先锋Shift改为铁壁反击：0.8秒架盾、移速35%、正常跳跃，减伤80%且免击退，吸收量上限40；结束时一次145范围反击，基础12加吸收量75%（基础上限42），不暴击、不触发连锁。普通敌人硬直0.28秒，首领0.06秒；基础冷却5.5秒，推进器最低压到2秒。游侠保留方向闪身与2.4秒基础冷却。
- 架盾、吸收与释放分别有金色护盾轮廓、充能刻度、扩散六边形和独立声音。角色技能不会因换装改变；死亡、受控、切关或施放裂地冲击会取消架盾。所有减伤、蓄能和反击由主机执行，预测只更新移动与显示。
- 金币恢复短暂喷出、旋转与自动吸附，吸附时有金色尾迹和闪光，抵达后显示金额并给全队入账。没有距离门槛，不需要来回捡；磁环每层加快12%追踪速度、最多60%。切关、胜负、所有队员倒下或飞行超时都会结清未抵达的金币，保留原共享与丰收规则。
- 金币与手动物品分开限量，最多64束；一束绘制少量金币，全场常规最多96枚装饰金币，低特效最多64。尾迹不保存无限历史；继续保留384粒子、32数字、12音频声部上限。
