# SomeSide v0.20.5 构建记录

日期：2026-10-07。Godot 4.7.2，Compatibility 渲染。

## 本轮改动

九种普通怪物和三类首领全部接入新插画图集：有机怪使用橄榄绿囊腹、翅膜和利爪；岩石怪使用高肩、厚背与大甲块；晶体怪使用蓝灰弧形甲壳、单眼和悬浮肢体。造型参考用户提供的黑色怪物剪影，强调体态、负空间和攻击器官。背景与玩家身体保持原版。

素材由内置图像生成工具生成，使用透明 PNG 图集；不是 SVG，也不是完整逐帧动画。原图、选定版本、提示词及来源说明位于 assets/art/enemy-design-v3/。运行时网格提供局部肢体运动与瞄准，飞行射击怪整体转向，口部/眼部绑定实际发射点。修正了画布坐标系正交方向错误造成的眼部倒置、头冠翻折，新增回归测试。

敌方弹丸、蓄力、范围爆发、折跃、修复和命中反馈统一使用克制的几何图形。有机攻击使用珠状弹丸和不等长弧片，岩石攻击使用有主次的尖块，晶体攻击使用锐利短线与尖角。原有攻击范围和瞄准规则保持不变。

红色闪烁虚线仅用于准备阶段。三种激光生效窗口从0.22秒延长至0.55秒；束体近端强、远端明显变淡，激活后撤去警戒边界。源点在持续期锁定，同一束对每个玩家最多造成一次伤害；晚进入光束仍会受伤。其他范围攻击仍为0.22秒。更长激光增加了持续占位压力，不能声称难度完全不变；自动测试验证临近发射时无道具单跳可越过完整伤害窗口。

## 验证边界

新身体采用程序化网格运动，尚未制作专门的逐帧跑步、挥击序列。大角度瞄准的自然程度、密集战斗下的主观观感及长期性能仍需试玩评价。旧录像和早期测试目录记录的是本轮早期几何版本，不作为最终插画版的视觉证据。

先前已通过四人同机ENet跨三关和中英混合验证；更换插画后未重跑完整联机流程。公网丢包、低端GPU、Firefox/Safari/手机本轮未验收。Web仍为单人，经HTTP(S)运行，不能双击index.html。
