# SomeSide v0.20.8 — 宝箱等级、绘制式预警与孢子

2026-10-08。

## 行为与美术

- 补给箱分为小/中/大三级，约34/46/56px宽，分别22/30/37px壳体高度。锁扣、嵌板、护边、铆钉、提手与高级箱饰条有独立结构；每级具有关闭、开启、锁定三种图像。使用原生SVG高倍率缓存，底座仍贴合平台。
- 每关包含三级补给箱，起点箱为小箱。中、大箱的基础价格分别乘1.8/3.2；主机建关时按等级预选奖励，客户端显示不重新抽取。第一关普通/精良/稀有/传说基础权重：小65/26/8/1，中40/34/21/5，大12/35/40/13。后续关卡进一步提高品质；候选物品与现有防重复规则仍参与实际抽选。
- 只有三选一商店展示具体物品。其他宝箱、装备仓、生命献祭、试炼信标隐藏物品图标、名字、描述、稀有度与物品风险；保留设施种类、费用、血量代价和挑战风险。打开/完成后奖励落地，接近掉落物查看实际效果，按E选择拾取。
- 所有圆形危险预警从顶部顺时针随主机蓄力进度画出红色虚线，不添加另一条进度弧，也不提前连接未画完部分。完成即切入伤害形态并撤掉预警。圆半径、蓄力时长、命中时机不变；提前完整显示圆周已按本轮要求改为逐步显示。
- 孢子准备态保留灰绿囊体与局部硬边亮面；攻击态改为两片厚薄变化的囊壁裂开、局部膜面高光及外喷种子，替代四组小圆/弧片装饰。活跃范围使用低对比灰绿色填充；黑色圆形衬底和外描边没有恢复。准备、攻击、结束使用实际危险状态，结束不留下完整轮廓。
