# SomeSide v0.16.0 步态、商店与角色技能更新

## 行为变化

- 重做游侠和先锋的前跑、后退素材，各有八个独立姿态。修正旧跑步中近、远腿交替不清的问题；后退改为较低姿势与短步，不再只倒放前跑。动画按实际显示位移推进，前跑周期 64 世界像素、后退 48，换向保留步相。开火的上身动作、鼠标瞄准、跳跃与现有武器动作继续独立组合。
- 修复三选一商店的高频抖动：悬浮相位原先误用屏幕 X 坐标，镜头移动会快速改变相位；现在使用稳定设施 ID。设施和地面掉落图标按最终尺寸生成并对齐物理像素，保留轻微悬浮和原交互、奖励规则。
- Shift 改为角色专属技能。游侠“相位闪身”按移动方向闪身，静止时沿瞄准方向，约 115 距离，基础冷却 2.4 秒，短暂无敌，不造成碰撞伤害。先锋“破阵突进”保持水平，约 90 距离，基础冷却 3.2 秒，对路径上每个目标造成一次基础 16 伤害，普通敌人硬直 0.32 秒，首领 0.08 秒。伤害可受构筑影响；先锋保留重力与可变跳高。
- 两种技能各有图标、颜色、冷却和说明；先锋增加金色前向冲击、命中粒子和两种独立合成声音。Tab 构筑页列出完整角色技能说明，中英文选角和指南同步更新。更换武器或主动装备不更换角色技能、不刷新其冷却。
- 伤害与碰撞由主机结算，客户端仅预测移动。每次突进记录已命中目标，受击、倒下、切关或控制会取消未完成动作；裂地冲击主动装备保留原行为，不继承先锋碰撞伤害。专属冲撞音采用独立自节流，避免同批普通命中声将它吞掉。

新增两张 1254×1254 RGBA 原图，保留 imagegen 输出字节与透明度，没有在 Python 中编辑像素。角色各 24 姿态，全部角色与怪物共 144 姿态、八张源纹理；源颜色纹理约 47.99 MiB，逻辑像素缓存约 3.08 MiB，仍在原 64/8 MiB 预算内。来源、完整提示词与动作取舍见 [v0.16 美术记录](../assets/sprites/ART_PROMPTS_v0.16.md)。
