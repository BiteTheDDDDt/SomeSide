# SomeSide v0.20.9 — 孢子 A、地刺 C 与瞬移动画

2026-10-08。

## 实现

- 孢子采用已选 A：灰绿闭合囊体、厚囊壁裂开、向外喷发的液瓣与种子、低矮残留。口部蓄力和飞行孢子共用闭合囊体素材，衔接落地爆发。
- 地刺采用已选 C：岩缝抬起、层叠厚石片破土、不同高度的硬边岩刃、碎石回落。覆盖潜地与石刺危险区域。
- 瞬移改为蓝灰实体裂隙，准备时聚拢，出发端收缩、落点端展开后消散。主机事件增加出发坐标，不改瞬移规则与伤害时机。
- 三张透明图集各八帧，阶段限制为四帧准备、三帧攻击、一帧无害余效；地面基线和瞬移中心逐帧对齐。源图像素保留，导入纹理约 6 MiB，共三张缓存纹理。来源和完整生成提示见 assets/fx/v0209/ART_NOTES.md。
- 保留渐进绘制的红色虚线预警和既有背景、怪物。攻击开始撤掉预警，攻击结束仅短暂保留碎片；地面素材裁剪在真实危险半径内，余效不恢复完整危险边界。
- 混战录像发现激光收尾的亚像素碎片触发退化多边形绘制错误；跳过不足一个像素的无意义碎片后复测无错误。此项不改变命中计算。
